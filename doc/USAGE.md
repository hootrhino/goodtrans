# 使用指南

## 单台电脑测试

### 使用虚拟串口
1. 安装虚拟串口驱动（如Virtual Serial Port Driver）
2. 创建虚拟串口对，如COM1-COM2
3. 启动两个程序实例：
   - 实例1：地址=1，验证码=1234，端口=COM1
   - 实例2：地址=2，验证码=1234，端口=COM2

### 使用USB转串口线回环
1. 将USB转串口线的TX和RX短接（使用跳线帽）
2. 启动程序，选择对应的串口号
3. 设置地址和验证码，点击连接

## 多台电脑测试

### RS485连接配置
1. 使用RS485转USB模块连接多台电脑
2. 设置相同的波特率（默认9600）
3. 每个节点设置不同的地址和相同的验证码

### 密码配对步骤
1. **发现节点**：启动程序后，节点会自动广播自己的地址
2. **选择节点**：在节点列表中选择要配对的节点
3. **设置配对密码**：
   - 点击"配对节点"按钮
   - 输入配对密码（双方必须使用相同的密码）
   - 点击确定发送配对请求
4. **等待响应**：
   - 如果对方接受配对，节点状态会显示为"已配对"
   - 如果密码错误，配对会失败
5. **开始通信**：配对成功后即可发送文本消息和文件

### 配对管理
- **查看配对状态**：节点列表会显示哪些节点已配对
- **取消配对**：选择已配对节点，点击"取消配对"
- **重新配对**：取消配对后可以重新进行配对

## 实际应用场景

### 工业设备通讯
1. **设备配置**：每个设备设置唯一的节点地址
2. **安全配对**：首次连接时进行密码配对
3. **数据传输**：配对成功后进行传感器数据或控制指令传输

### 实验室数据采集
1. **节点部署**：将多个传感器节点连接到同一总线
2. **集中管理**：使用一个中心节点收集所有数据
3. **权限控制**：只有配对的节点才能发送数据到中心节点

## 故障排除

### 常见问题

**无法发现节点**
- 检查串口连接是否正确
- 确认所有节点使用相同的波特率
- 检查是否有其他程序占用串口

**配对失败**
- 确认双方使用相同的配对密码
- 检查节点地址是否冲突
- 确认验证码设置一致

**通信中断**
- 检查物理连接是否松动
- 确认配对关系是否有效
- 查看是否有干扰源

### 调试技巧

**使用日志**
- 所有消息都会显示在消息传输面板
- 文件接收会有弹窗提示

**使用回环测试**
- 使用test_echo.py进行回环测试
- 验证串口硬件是否正常工作

## 高级配置

### 自定义波特率
在SerialManager类中可以修改默认波特率：
```python
self.serial = serial.Serial(port, baudrate=115200, timeout=1)
```

### 修改协议参数
- 在protocol.py中修改HEADER、VERIFY_CODE等参数
- 确保所有节点使用相同的协议版本

## 性能优化

### 文件传输优化
- 对于大文件，可以适当增大CHUNK_SIZE
- 在网络稳定环境下可以减少重传次数

### 节点发现优化
- 可以调整DISCOVER_INTERVAL来平衡发现速度和网络负载
- 在节点较多时增加超时时间

## 安全建议

### 密码管理
- 使用强密码（建议8位以上混合字符）
- 定期更换配对密码
- 不要在公共场合泄露配对密码

### 网络隔离
- 在生产环境中使用物理隔离的串口网络
- 避免与敏感系统共享串口总线
