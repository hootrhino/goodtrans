# 节点密码配对功能使用指南

## 功能概述

串口通讯工具新增了节点密码配对功能，确保只有经过授权的节点才能进行通信。在发现节点后，发送文件和消息之前，需要先进行密码配对。

## 配对流程

### 1. 基本配对步骤

#### 步骤1：启动程序
```bash
python main.py
```

#### 步骤2：配置串口连接
- 在"串口配置"面板中设置节点地址和验证码
- 选择可用的串口端口
- 点击"连接"按钮建立连接

#### 步骤3：发现节点
- 程序会自动进行节点发现
- 在"节点列表"中查看发现的节点
- 未配对的节点显示为："节点地址"
- 已配对的节点显示为："节点地址 (已配对)"

#### 步骤4：配对节点
1. 在节点列表中选择要配对的节点
2. 点击"配对节点"按钮
3. 在弹出的对话框中输入配对密码
4. 点击确定发送配对请求

#### 步骤5：验证配对
- 配对成功后，节点状态会更新为"已配对"
- 现在可以向该节点发送消息和文件

### 2. 配对密码设置

#### 密码规则
- 密码长度：建议4-20个字符
- 字符类型：支持字母、数字、特殊字符
- 密码要求：区分大小写

#### 密码共享
- 配对双方必须使用相同的密码
- 建议在配对前通过其他安全渠道共享密码
- 每个节点对可以使用不同的密码

### 3. 配对管理

#### 查看配对状态
- 在节点列表中查看每个节点的配对状态
- 配对状态标签显示当前已配对的节点数量

#### 取消配对
1. 在节点列表中选择已配对的节点
2. 点击"取消配对"按钮
3. 确认取消配对操作

#### 重新配对
- 取消配对后可以重新配对
- 需要重新输入密码

## 使用场景示例

### 场景1：单台电脑测试（虚拟串口）

#### 创建虚拟串口对
```bash
# 使用com0com创建虚拟串口对
# 例如：COM1 <-> COM2
```

#### 启动两个程序实例
```bash
# 终端1：启动节点1
python main.py
# 设置地址为1，使用COM1

# 终端2：启动节点2
python main.py  
# 设置地址为2，使用COM2
```

#### 配对过程
1. 在两个程序中都设置相同的配对密码，如"test123"
2. 在节点1的程序中选择节点2进行配对
3. 输入密码"test123"完成配对
4. 现在可以互相发送消息和文件

### 场景2：多台电脑实际连接

#### 硬件连接
- 使用RS485转换器连接多台电脑
- 确保所有设备使用相同的串口参数

#### 配对配置
1. 每台电脑设置唯一的节点地址
2. 所有节点使用相同的验证码
3. 通过安全方式共享配对密码

#### 配对操作
- 每个节点可以独立选择要配对的节点
- 支持一对多配对关系

## 故障排除

### 常见问题

#### 1. 配对失败
**问题描述**：输入正确密码后配对失败

**可能原因**：
- 网络连接不稳定
- 节点不在线
- 密码输入错误

**解决方法**：
1. 检查串口连接
2. 刷新节点列表确认节点在线
3. 重新输入密码

#### 2. 无法发现节点
**问题描述**：节点列表为空

**解决方法**：
1. 点击"刷新节点"按钮
2. 检查串口连接
3. 确认所有节点都已连接并配置正确

#### 3. 发送消息失败
**问题描述**：向已配对节点发送消息失败

**解决方法**：
1. 确认节点已配对（显示为"已配对"）
2. 检查串口连接状态
3. 确认目标节点地址正确

## 安全建议

### 密码安全
- 使用强密码（包含大小写字母、数字、特殊字符）
- 定期更换配对密码
- 不要在代码中硬编码密码

### 网络安全
- 在可信网络环境中使用
- 考虑使用加密串口通信
- 限制物理访问权限

### 节点管理
- 定期清理未使用的配对关系
- 记录所有配对节点和对应密码
- 建立节点白名单机制

## 高级配置

### 自动配对（可选）
可以扩展支持自动配对模式：
```python
# 设置自动配对密码
manager.set_auto_pair_password("shared_password")
```

### 配对超时设置
```python
# 设置配对请求超时时间（秒）
manager.set_pair_timeout(30)
```

### 最大配对节点数限制
```python
# 设置最大配对节点数
manager.set_max_paired_nodes(10)
```

## 总结

节点密码配对功能为串口通讯提供了基本的安全保障，确保只有授权的节点才能进行通信。通过简单的图形界面操作，用户可以轻松管理节点间的配对关系。

该功能特别适用于：
- 工业设备间的安全通信
- 实验室数据采集系统
- 多节点传感器网络
- 需要访问控制的串口应用

如需更高级的安全功能，可以考虑添加数据加密、数字签名等机制。
